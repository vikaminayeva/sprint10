Автоматизация и управление файловой системой на Bash (Linux Core) 🐧🐚

Проект, демонстрирующий базовые навыки администрирования Linux, работы с командной строкой и написания Bash-скриптов для автоматизации рутинных задач. В рамках проекта создан скрипт `task.sh`, который манипулирует изолированной структурой директорий и файлов.

##  Описание проекта
Проект представляет собой синтетический Bash-скрипт, последовательно выполняющий комплекс операций над файловой системой (создание, копирование, поиск, фильтрация данных и удаление) строго в рамках текущей рабочей директории приложения с использованием относительных путей.

### Ключевые требования к скрипту:
*   **Изоляция и чистота:** После завершения работы скрипт не оставляет после себя никаких следов (созданные временные папки и файлы удаляются автоматически), выводя в консоль только эталонный результат.
*   **Портативность:** Отсутствие абсолютных путей гарантирует, что скрипт корректно отработает на любой Unix-подобной системе (Linux, macOS).

---

##  Задействованные команды и концепции Linux

В ходе написания скрипта были применены следующие инструменты командной строки:
*   `mkdir` и `rm` / `rmdir` — создание и рекурсивное удаление структуры папок.
*   `touch`, `cp`, `mv` — создание пустых файлов, их копирование и перемещение между директориями.
*   `cat` и `echo` — вывод содержимого файлов и запись текста в поток стандартного вывода.
*   `chmod` — управление правами доступа (выделение прав на исполнение скрипта `+x`).
*   `find` и `ls` — сканирование директорий и поиск файлов по кастомным критериям.
*   `grep` — фильтрация текстовой информации и поиск по подстроке.

###  Продвинутые механики Bash:
1.  **Перенаправление потоков (`>` и `>>`):** Перезапись файлов и добавление данных в конец существующего файла (логирование).
2.  **Конвейеры / Пайпы (`|`):** Перенаправление вывода одной команды на вход другой (например, фильтрация списка файлов через `grep`).
3.  **Локальные переменные окружения:** Использование динамических переменных сессии Bash.

##  Инструкция по запуску

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd название_папки_проекта
   ```
3. Сделайте файл скрипта исполняемым (выдайте права на запуск):
   ```bash
   chmod +x task.sh
   ```
4. Запустите скрипт:
   ```bash
   ./task.sh
   ```
